Iron Sentinel / hostile knight with a two-handed claymore

Manual spawn: anpc_spawn iron_sentinel
Male Breton, Knight base class, hostile, Brave, wander radius 6.
Spawns on its own only in dungeons: 15% chance of 1-2 in ruined castles,
human strongholds and prisons. No town or wilderness spawns.
Uses the shared breton_oblivion_skyrim name pool and a custom 64x64 portrait.
No spells: the explicit empty spellbook disables inherited class spells.

14 sheets, 8 directions, 8 fps, 256-pixel cell height, 87 animation frames.
Both claymore attacks land on frame 3 (actionFrame). Includes hit blood,
the growing death pool and yellow casting effects.
death_1 ends with the knight lying flat face down, the claymore beside him.

Source: Models/iron_sentinel (README there). The claymore is the Oblivion iron
claymore: personal use only, do not redistribute these sheets as they are.
