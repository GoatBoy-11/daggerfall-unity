Breton Nightblade

Male Breton dagger fighter with magic, rendered from Models/breton_1/breton_1_1.blend.
Manual spawn: anpc_spawn breton_nightblade
No ambient spawns are enabled initially. Normal bravery: defends himself when attacked
and can flee at low health. Wander radius: 6.

Shock, Paralysis and Invisibility; 110 magicka; 4-7 second casting cooldown;
magicka recovers on area entry. Spells and values are editable in npc.json.
Name pool: breton_oblivion_skyrim, with separate male/female lists and shared surnames.
Names follow an Oblivion/Skyrim-inspired mix of French-sounding and British/High Rock
names; the pool includes original variants and does not represent a list of canon NPCs.

12 sprite sheets / 744 cells / 8 directions / 8 fps / 256-pixel cells.
Shared animation frames match the Dunmer: attack_1 impact 3, attack_2 impact 2.
Death includes its final resting pose. run and talk_1 are included for future triggers;
the runtime currently uses idle, walk, hit, attack, cast and death.
The original Blender source is unchanged. breton_1_marked.blend is the working copy
with impact markers. No new actions were authored.

Model sprite sources: Models/breton_1/sprites.
Previews, name examples and validation: output/breton_1.
